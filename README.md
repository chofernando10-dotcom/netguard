# NetGuard

Herramienta en Python para auditar configuraciones de red, detectar riesgos de seguridad y simular reglas de control de acceso (ACLs).

## Estructura del proyecto
- `policies/`: Reglas de seguridad configurables en YAML.
- `sample_configs/`: Archivos de configuración de ejemplo para pruebas.
- `src/`: Código fuente modular (lector, analizador, simulador, remediación y reportes).
- `tests/`: Pruebas unitarias.
